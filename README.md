# 🐾 Petly — Plataforma Web para la Tienda de Mascotas La Yunta

Plataforma web integral desarrollada para la tienda de mascotas **La Yunta** (Toledo, Norte de Santander, Colombia).

## 🚀 Funcionalidades Principales
- **Catálogo y Tienda Virtual:** Consulta de productos, categorías, buscador, carrito de compras y gestión de pedidos.
- **Agendamiento de Citas:** Programación de servicios de peluquería y atención veterinaria con control de disponibilidad de horarios.
- **Gestión de Usuarios:** Registro, inicio de sesión seguro y perfiles diferenciados (Clientes y Administradores).
- **Panel Administrativo:** Control de inventario con alertas de stock bajo, confirmación de pagos, gestión de citas y reportes de ventas.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript.
- **Backend:** Node.js con Express.
- **Base de Datos:** MySQL 8.0.
- **Control de Versiones:** Git y GitHub.
